# Spring Boot 2 Demo 重构计划

**目标:** 按 Spring Boot 最佳实践重构 `spring-boot2-demo`，修正包结构、规范注解、添加 DTO 和异常处理。

**架构:**
- 按领域分包（user/、tenant/、common/）替代按层分包（controller/、business/、repository/）
- 使用 DTO 隔离 API 与实体
- 添加 `@ControllerAdvice` 全局异常处理
- 修复所有不规范的注解/注释顺序

---
